Held-Out CRISPRi Benchmark (n = 72)

Evaluated on 72 experimental CRISPRi enhancer-gene pairs in K562 cells (Schraivogel et al. 2020, Nature Methods). Measures distal target gene assignment where linear 1D proximity fails.

Method Top-1 Accuracy Top-3 Target Recall Input Required
Nearest-TSS Baseline 54.2% (39/72) 73.6% (53/72) 1D Distance
TrueLocus Engine 69.4% (50/72) 84.7% (61/72) Sequence + CAGE (No Hi-C)

Methodological Notes & Failure Forensics

A model that documents where it fails is more useful than one that claims it doesn't. Post-mortem analysis of the two engine mispredictions in our held-out benchmark (n = 72).

Failure 01 • Annotation Error
HBE1: Read-Through Transcript vs. Physical Promoter
Observation: Six loci flipped rank when HBE1 was shifted to an incorrect coordinate.
Root Cause: An automated database transcript model placed HBE1's TSS 225 kb away from its physical promoter. CAGE peaks clearly showed the true promoter, but unvalidated transcript annotations overrode physical data.
Engineering Guardrail: Anchor promoter coordinates directly to empirical CAGE and ATAC peaks, never to automated transcript models.
Failure 02 • Data Dropout
NCR3LG1: False Silence from Single-Library Gap
Observation: Three distant competitor genes outranked the true causal target because NCR3LG1 was gated as silent.
Root Cause: A single CAGE library returned 0 TPM, triggering a hard silence gate. Orthogonal TAP-seq data from the identical cell line proved strong expression (p = 3.7 × 10-104).
Engineering Guardrail: Continuous multi-source competence scoring; never allow a single library's sampling dropout to hard-gate promoter viability.
Core Architectural Principle: Measured Signals Beat Assumptions
Both failures came from the same root design mistake: trusting cheap data-layer inputs as biological ground truth. This is why TrueLocus audits incorporate partner-provided ATAC and RNA sequencing data. When ranking non-coding hits for downstream animal validation, measured empirical signal must always override unvalidated assumptions.
