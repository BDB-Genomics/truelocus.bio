Evaluated on 72 experimental CRISPRi enhancer-gene pairs in K562 cells (Schraivogel et al. 2020, Nature Methods). Measures distal target gene assignment where linear 1D proximity fails.

Methodological Forensics

Engine Failure Analysis on Ground-Truth Data

In our 72-pair held-out CRISPRi benchmark, our initial model configurations exhibited two specific failure modes that guided architecture updates:

Failure 1 • HBE1 (Annotation Error)

The database placed HBE1's transcription start 225 kb from its real promoter. CAGE peak data identified the true promoter directly, but a read-through transcript model shifted coordinates.

Resolution: Anchor promoters strictly to measured CAGE peaks.
Failure 2 • NCR3LG1 (Data Dropout)

A single CAGE library returned 0 TPM, leading to false promoter gating. TAP-seq validation demonstrated strong expression (p = 3.7 × 10-104).

Resolution: Multi-source expression consensus scoring.
Case Study • Methodological Forensic

The 1p13 LDL Locus: Where Linear Proximity Fails

On the 1p13 cholesterol locus (Musunuru et al., Nature 2010; PMID 20686566), the causal variant rs12740374 creates a de novo C/EBP binding site. Because the proximal promoter PSRC1 is physically closer (9.1 kb vs 123 kb) and active in adult liver, linear proximity defaults to PSRC1 (#1, 42.2% share) and ranks causal SORT1 at #6 (4.8% share).

Candidate Gene Distance Liver TPM Target Score Share Status
PSRC1 (Nearest TSS) 9.1 kb 1.86 0.3662 42.2% #1 (Proximal Competitor)
CELSR2 25.4 kb 0.85 0.1632 18.8% #2 (Co-regulated)
MYBPHL 32.2 kb 0.00 0.1281 14.8% #3 (Unexpressed)
SARS1 61.1 kb 34.85 0.1242 14.3% #4 (Active)
PSMA5 151.5 kb 17.66 0.0456 5.2% #5 (Active)
SORT1 123.0 kb 2.39 0.0413 4.8% #6 (True Causal Target)
Evaluated on TrueLocus v1.8. Expression from GTEx Portal API v2 (gtex_v10 adult liver, 100+ donors).
•
Multi-eQTL Co-activation: rs12740374 upregulates both PSRC1 and SORT1 by >12-fold in liver.
•
Proximity Bias: Linear distance gives proximal PSRC1 a strong default score advantage over SORT1 at 123 kb.
•
Functional Separation: Mouse functional assays proved Sort1 drives LDL-C changes (>2-fold), while Psrc1 had zero phenotypic effect.
